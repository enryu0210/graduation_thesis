## 2. 원고 정정 (1단계, 필수)

### 2.1 수치·사실 불일치

- [ ] 4.1절 FPR 2.73%/0.36% vs Table 3 의 2.00%/0.35%(seed 42), 1.27%/0.24%(seed 43). 출처를 하나로 맞춘다.
- [ ] 스캐너 비율 97.8% vs `srbh_normal_strata.json` 95.9%(54,600/56,906, 실사용자 550, 혼합 1,756) vs Fig. 1 의 96%. 97.8% 는 출처를 찾지 못했다.
- [ ] "r_N 20%p 이상"은 RGB 1차 H-G4(+24.9pp)의 잔재다. Table 2 의 r_N(7.1·8.9·1.1·0.0%)과 맞지 않는다.
- [ ] "실행 간 표류 4~7%" vs t2 0.3451ms 와 0.563ms(1.6배).
- [ ] 3.1절(55행) "실제 길이 L 그대로" vs 코드의 2,304바이트 절단(`latency_fair.py:65`).
- [ ] 헤드라인 10.6~12.3배만 쓰고 있다. seed 44·45 의 B0 76.0·42.4배, seed 42 재학습 23.5배를 함께 쓴다. F1 차이는 네 seed 에서 −0.03, −0.32, +0.08, −0.24%p 다.
- [ ] VI절 E15 수치가 재학습 실행 값임을 밝힌다.
- [ ] VI절 "80~280배", "0.3~0.8%p" 를 실제 값으로 고친다: char-CNN 80배·−0.30~−0.85%p, DL-C 284~289배·−0.40~−0.52%p. 차단 실패 관점의 근거임을 분명히 한다.
- [ ] DistilBERT 와 char-CNN 차이 +0.30%p(p 0.57), +0.85%p(p 0.074), −0.01%p 를 병기한다.

### 2.2 과장·표현

- [ ] "미세조정 편차로 재현 실패"는 단정이다. seed 는 fold 분할과 초기화를 함께 바꾼다(`StratifiedKFold(random_state=seed)`).
- [ ] "원 논문 설정"(41·165·184·198행)을 "128 토큰 조건"으로 바꾼다. WAMM 은 13클래스·AdamW·8 vCPU, 우리는 4클래스·Adam 이다.
- [ ] "입증한다", "성패는 ~에 달려 있으며", "동등한 정확도"를 낮춘다.
- [ ] "사전 등록"을 "사전 고정"으로 바꾼다(자체 커밋, 블라인드 충돌). 51.6→12.3배 정정을 공개한다.
- [ ] "보정 p"와 Holm 표기를 통일한다.
- [ ] "봉인 시험"(106행) 39,891행 결과가 논문에 없고 고정 test 는 아홉 번 평가에 쓰였다. 최종 1회 평가(5단계)를 하거나 표현을 바꾼다.

### 2.3 RQ1 제외에 따른 정리

## 3. 구조 개편 (1단계)

```text
I.   서론 : 질문 3개로 축소 (공정 지연 질문은 대조 측정이 없어 답이 없음)
II.  관련 연구 : 데이터·클래스·지표·지연 비교표, 국내 문헌 추가
III. 대상 구성 : 구조도 추가, 코드명을 서술형 이름으로 교체
IV.  실험 설계 : 데이터·층 정의·지표·지연 측정·사전 판정 기준
V.   결과 (질문과 1:1 대응)
     5.1 오류 분해 : 왜 2차가 필요한가
     5.2 속도–정확도 : 4 seed 표와 신뢰구간
     5.3 배포 분포 : 검증 분포 대 실사용자, 정밀도 재가중, 꼬리 지연
     5.4 넘김 판단
     5.5 slowdown·회피 : 한계 절에서 승격
VI.  논의와 배포 지침
VII. 타당성 위협 : 내적·외적·구성 타당도
VIII.결론 : 초록 반복을 줄이고 "무엇이 남고 무엇이 사라졌는가" 위주로
```

효과가 큰 순서:

1. [ ] 핵심 메시지를 "가속 달성"에서 "엄격한 조건에서 무엇이 남고 사라지는가"로 옮긴다.
2. [ ] Fig. 1 을 다시 만든다. RGB 시리즈와 약 25개 범례, "G4-corrected" 를 없애고 같은 조건 프런티어와 seed 산포 그림으로 바꾼다. 양식은 "육안으로 식별되지 않으면 게재 불가"라고 명시한다.
3. [ ] 내부 코드명을 없앤다(DL-A 25회, B0 24회, G2 17회, E12 11회, E13·E14 9회, DL-C 10회 등). "E16·B3·T8 미실시" 문장도 뺀다.
4. [ ] Table 2(9열 11행)를 "단독·조기 종료 대 char-CNN"과 "캐스케이드 대 DistilBERT"로 나누고 Reference 열을 통일한다. 4 seed 표를 추가한다.
5. [ ] 초록(국문 1,330자, 영문 274단어)을 줄인다. 볼드를 없애고 수치를 절반으로 줄이며, E14 배수가 DL-A 대비임을 밝힌다.

그 밖에:

- [ ] VI절 다섯째 한계 문단을 해체하고 T5·T10 을 강건성 소절로 옮긴다.
- [ ] 고전 기준선을 표에 한 행 복원한다. WAMM 최고는 XGBoost, 우리 TF-IDF+LR 은 0.29ms·F1 0.938 이다.
- [ ] 참고문헌의 arXiv 5/21 을 점검하고 국내 문헌·JKIISC 인용을 추가한다.
- [ ] 양식 대조: 그림·표 제목과 내용, 참고문헌은 영문. 그림 제목은 아래, 표 제목은 위.

## 5. 아직 확인하지 못한 것

- 위 수치 대조는 문서 기준이다. 층 인원을 빼면 원본 JSON 으로 재계산하지 않았다. 2단계에서 데스크톱으로 확인한다.
- 약점 표의 "추정"은 원본 없이 손으로 계산한 값이다. 그대로 논문에 쓰지 않는다.
- 학회 별도 투고 규정: 양식(`#(투고양식)submission_form_2026.hwp`)에는 초록 길이·쪽수 제한이 없다.
- 서지 [2]·[3]·[13]: X-WAD 는 PDF 가 없다.
- 3.3% 의 의미: OWASP 사전확률이라 요청 단위가 아닐 수 있다(기억 기반, 원문 확인 필요).
- 층 판별 코드 위치: `src/data/srbh_normal_strata.py` 경로에는 없다.
- 교수 피드백: 대기 중이다.
