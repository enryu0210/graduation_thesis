# docs/archive — 지나간 시점의 기록

**그 시점에는 맞았지만 지금 기준이 아닌 문서**를 둔다. 삭제하지 않는 이유는 심사에서
"언제 무엇을 근거로 판단했나"를 되짚을 일이 있기 때문이고, 현행 문서와 섞어 두지 않는 이유는
낡은 수치·용어를 현행으로 오독하는 사고가 실제로 났기 때문이다.

## 읽을 때의 규칙

- ⚠️ **여기 있는 수치·용어는 현행이 아니다.** 지금 무엇이 유효한지는 항상
  **`docs/CURRENT_BASELINE.md`** 로 먼저 확인한다(시기 구분 §0.1, 유효/폐기 대조 §1).
- 특히 자주 어긋나는 것: **MCC**(2026-08-13 제거) · **`제안 CNN`**(금지어, 현행은 `RGB CNN`) ·
  **주 데이터셋**(SR-BH 2020 으로 교체 확정).
- 여기 있는 문서를 **다른 문서가 참조하게 만들지 않는다.** 참조가 필요하면 그 내용은
  현행 문서로 옮기고 여기에는 원본만 남긴다.
