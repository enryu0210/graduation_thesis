## 0. 전제 — 입력은 제안 CNN 과 **완전히 동일**하다 ⭐

이 arm 의 목적은 **"이미지화 파이프라인은 그대로 두고 분류기만 CNN ↔ ViT 로 교체"** 하는 것이다.

| | 입력 파일 | 채널 |
|---|---|---|
| 제안 CNN (기존) | `data/images/payload_4class_*_48*.npz` | gray 1ch / RGB 3ch |
| **ViT (본 문서)** | **동일** | **동일** |
| **하이브리드 (본 문서)** | **동일** | **동일** |

> ⚠️ 용어 주의: 이 문서에서 **"단일 ViT"** 는 *CNN stem 없이 Transformer 블록만으로 구성한 모델*을
> 뜻하며, **입력이 다르다는 뜻이 아니다.** (초안에서 "순수 ViT"라 쓴 표현이 "다른 입력을 쓰는 모델"로
> 오해를 불러 용어를 교체했다.) 두 변형 모두 gray/RGB 이미지를 그대로 먹는다.

## 0.1 한 줄 요약

1순위는 **동일 입력·동일 평가에서의 CNN ↔ ViT 교체 비교**(gray/RGB 각각)다.
2순위(부가 질문)로, ViT 의 패치 기하를 바꾸면
*"바이트-플롯 이미지에서 **2D 지역성(locality)** 은 정말 의미가 있는가?"* 에 답할 수 있다(§2~3).
후자는 선행연구(Nataraj 계열, VulCNN, MDMC)가 **묻지 않은 질문**이라 신규성 논거가 되지만,
"CNN 처럼 쓴다"는 본래 목적과는 별개 트랙이므로 우선순위를 낮춰 둔다.

## 1. 왜 ViT 인가 — 교수 지적과의 연결

교수의 요구(docs/06 §0.1)는 둘 중 하나였다:
**(a) 정확도가 낮아지더라도 기존이 못 잡던 것을 잡거나, (b) 여러 방법을 시도해 개선안을 채택.**

ViT 도입은 (b) 의 정공법이면서, 아래 §3 의 패치 기하 실험을 통해 (a) 로도 연결된다.
단, **"ViT 가 CNN 보다 정확할 것"이라는 기대는 근거가 약하다**(§6 리스크). 이 arm 의 가치는
정확도 경쟁이 아니라 **표현 가설의 검증**에 있다는 점을 처음부터 못박는다.

---

## 2. 핵심 통찰 — 정사각 패치는 바이트 연속성을 깬다 ⭐

현재 이미지화는 페이로드 바이트열을 **폭 W=48 로 접어서** 48×48 로 만든다(docs/03).
따라서 이미지 좌표 (row r, col c) 의 픽셀은 **바이트 오프셋 `r*48 + c`** 다.

| 이미지에서 인접 | 실제 바이트 오프셋 차이 | 의미 |
|---|---|---|
| 가로 이웃 (r, c) ↔ (r, c+1) | **+1** | 실제로 붙어 있는 바이트 ✅ |
| 세로 이웃 (r, c) ↔ (r+1, c) | **+48** | 48바이트 떨어진 남남 ❌ |

즉 **세로 방향 지역성은 이미지화가 만들어낸 인공물(artifact)** 이다.
그런데 CNN 의 3×3 커널도, ViT 의 8×8 정사각 패치도 **가로/세로를 동등하게 취급**한다.
→ 지금까지의 모든 실험은 "48바이트 주기성"이라는 우연한 구조에 모델을 맞춰온 셈이다.

**설계 결정**: ViT 의 패치를 **행 패치(row patch, 1×48 또는 2×48)** 로 두면,
토큰 1개 = **연속된 48(또는 96)바이트 조각** 이 되어 바이트 연속성이 정확히 보존된다.
`' OR 1=1 --` 같은 공격 조각이 한 토큰 안에 온전히 담기고, 토큰 간 관계는 self-attention 이 맡는다.

> 검증 완료(2026-07-18): `timm.models.VisionTransformer(img_size=48, patch_size=(1,48))` 로
> 비정사각 패치가 그대로 동작함을 확인(토큰 48개, 파라미터 2.71M).

## 3. 실험 설계 — 패치 기하 ablation (이 arm 의 주력)

동일 ViT 백본(embed_dim=192, depth=6, heads=3)에서 **패치 기하만** 바꿔 비교한다.

| 조합 | 패치 | 토큰 수 | 토큰 1개가 담는 것 | 가설 |
|---|---|---|---|---|
| V-sq8 | 8×8 | 36 | 8행×8열(= 8개의 불연속 8바이트 조각) | 기준선(기존 관행) |
| V-sq4 | 4×4 | 144 | 4개의 불연속 4바이트 조각 | 세밀하지만 여전히 불연속 |
| **V-row1** | **1×48** | **48** | **연속 48바이트** | **바이트 연속성 보존 → 최고 성능 예상** |
| V-row2 | 2×48 | 24 | 연속 96바이트 | 문맥은 넓고 토큰은 적음 |
| V-col | 48×1 | 48 | 48바이트 간격 스트라이드 샘플 | **음성 대조군**(가장 나쁠 것) |

**왜 V-col 을 넣나**: "행 패치가 좋다"가 단순히 토큰 수(48개) 때문인지, 진짜 **바이트 연속성** 때문인지
구분하려면 토큰 수는 같고 연속성만 깨진 대조군이 필요하다. 이게 있어야 인과 주장이 성립한다.

**성공/실패 기준을 미리 못박는다(HARKing 방지)**:
- V-row1 이 V-sq8 대비 **MCC 유의하게 우세**(5-fold paired t-test, p<0.05) → "2D 지역성은 인공물" 주장 성립.
- 차이가 유의하지 않으면 → "패치 기하는 중요하지 않다"를 **음성 결과로 정직하게 보고**하고,
  이미지화 자체가 바이트 순서에 둔감하다는 해석을 단다(이 역시 발표 가치 있는 결과).

## 4. 아키텍처 3안과 선택

| 안 | 구성 | 파라미터(실측) | 장점 | 단점 |
|---|---|---|---|---|
| **A. 단일 ViT** (`--model vit`) | timm ViT, dim192/depth6/heads3, 패치 8×8 | **2.69M**(gray) / **2.71M**(rgb) | CNN stem 없는 대조, 패치 기하 교체 가능 | 데이터 20만장으로 ViT 는 데이터 부족 위험 |
| **B. 하이브리드** (`--model hybrid`) | conv 2블록 → 12×12=144토큰 → Transformer 4층 | **0.58M** | 지역성 귀납편향 유지 + 전역 attention, 데이터 효율 좋음 | CNN stem 이 있어 "ViT 단독 성능"은 아님 |
| C. 사전학습 전이 | ImageNet DeiT-Tiny, 48→224 업샘플 | 5.7M | 표현력 최고 | 처리량 붕괴(§6), 48×48 도메인과 ImageNet 갭 큼 |

**A·B 는 구현 완료(2026-07-18), C 는 하지 않는다.**
- A 는 "CNN stem 없이도 되는가"라는 대조군이자, §3 패치 기하 실험의 **유일한 도구**다
  (하이브리드는 conv stem 이 공간을 줄여 패치 개념이 사라진다).
- B 는 "성능 개선안 채택"(교수 요구 b) 에 가장 현실적인 후보다. 20만장 규모에서 단일 ViT 가
  CNN 을 이기기는 어렵지만, 하이브리드는 이길 가능성이 있다.
- C 는 **우리 논문의 유일한 확실한 우위(처리량)** 를 스스로 무너뜨린다 → 하지 않는다.

> 참고: 제안 CNN 은 **93,988** 파라미터다. hybrid 는 6배, vit 은 29배 크다.
> **성능이 비슷하다면 CNN 이 우수하다**는 해석을 논문에서 빠뜨리지 말 것.

## 5. 기존 파이프라인과의 접합점 (구현 비용이 작은 이유)

1. **RGB 채널 인프라 그대로 재사용** — ViT 의 patch embedding 은 내부적으로 `Conv2d(in_chans, dim, kernel=patch, stride=patch)` 다.
   즉 `in_chans=3` 만 넘기면 Phase 7 의 채널 인코더(`raw_byte/char_class/byte_delta` …)가 **수정 없이** 붙는다.
   → RGB ablation × 패치 기하 ablation 을 곱집합으로 돌릴 수 있다.
2. **train.py 에 모델만 추가** — `IMAGE_MODELS = {"cnn"}` → `{"cnn", "vit", "hybrid"}`.
   데이터로더·조기종료·`metrics.py` 평가·CV 스크립트가 전부 그대로 재사용된다.
   ⚠️ CLAUDE.md 의 "`--track` choices 5곳 갱신"은 **트랙 추가 때만** 해당 — 모델 추가는 무관하다.
3. **위치 임베딩 = 바이트 오프셋** — 행 패치를 쓰면 학습형 1D pos-embed 가 문자 그대로
   "이 조각이 페이로드의 몇 번째 48바이트인가"를 인코딩한다. 페이로드는 앞부분(경로·파라미터명)과
   뒷부분(값)의 역할이 다르므로 의미 있는 편향이다.

**신규 파일 예정**: `src/models/vit.py` (`build_model(num_classes, in_channels, patch_size, variant)`),
기존 `cnn.py` 와 동일한 팩토리 인터페이스를 지켜 `train.py` 가 이름으로만 분기하게 한다.

## 6. 리스크 — 정직하게 먼저 적는다 ⚠️

1. **데이터 규모 부족**: ViT 는 귀납편향이 약해 통상 수백만 장 이상을 요구한다. 우리 풀은 20만 장이고
   클래스가 4개뿐이라, 단일 ViT(A)가 CNN 에 **질 가능성이 높다**. → B(하이브리드)를 병행하는 이유.
2. **처리량 붕괴 = 현재 유일한 우위 상실**: docs/04 §5 에서 제안 CNN 의 실질 기여는
   "char-CNN 대비 13.6배 빠른 추론(81,964 samples/s)" 이다. ViT-tiny 급은 이보다 **5~10배 느릴 것으로
   예상**(실측 필요). 정확도도 못 이기고 속도도 잃으면 이 arm 은 논문에서 **음성 결과**로만 남는다.
   → 그래서 §3 의 "패치 기하 지식 기여"를 주 목적으로 삼는 것이다(정확도와 무관하게 남는 결과).
3. **범위 확대 리스크**: RQ3(방어/adversarial training)이 **아직 착수조차 안 됐다**(docs/05 §미완).
   ViT arm 은 RQ1 의 곁가지이므로, RQ3 를 밀어내면서까지 할 일은 아니다.
   → **순서 권고: RQ3 먼저, ViT 는 그다음.** 단 §3 의 패치 기하 실험만은 저비용(모델 5개 학습,
   GPU 1~2시간)이라 RQ3 와 병행 가능하다.
4. **해석가능성은 "덤"이지 근거가 아님**: attention rollout 으로 "어느 바이트 구간이 판단을 이끌었나"를
   시각화할 수 있고(RQ2 회피 성공 사례 분석과 연결), 이는 CNN 의 Grad-CAM 보다 자연스럽다.
   다만 **해석 그림만으로는 기여가 되지 않는다** — 반드시 정량 지표와 함께 보고한다.

## 7. 실행 계획 (구현 시)

```bash
# 1순위) CNN ↔ ViT 교체 비교 — gray / RGB 각각, 입력은 제안 CNN 과 동일
python src/models/train.py --model vit    --channels gray
python src/models/train.py --model vit    --channels rgb --rgb-encoders raw_byte,char_class,byte_delta
python src/models/train.py --model hybrid --channels gray
python src/models/train.py --model hybrid --channels rgb --rgb-encoders raw_byte,char_class,byte_delta

# 2순위) 패치 기하 ablation (단일 ViT 전용 — hybrid 는 conv stem 이 대신함)
python src/models/train.py --model vit --patch 1x48    # 행 패치(핵심 가설)
python src/models/train.py --model vit --patch 48x1    # 음성 대조군

# 유의성 판정 — 단일 split 로는 결론 못 냄(docs/04 §5 재현성 메모)
python src/eval/cross_validate.py --model vit --channels rgb --rgb-encoders raw_byte,char_class,byte_delta
python src/eval/cross_validate.py --model hybrid --channels rgb --rgb-encoders raw_byte,char_class,byte_delta
```

**반드시 CV 로 판정할 것**: 2026-07-18 재현 실험에서 단일 split 의 실행 간 변동이 ±0.11pp 였고,
이는 조합 간 차이보다 크다. CNN↔ViT 비교도 패치 기하 비교도 동일한 함정에 빠진다.

**산출물 태그**: `vit` 은 패치 기하가 다르면 다른 실험이므로 파일명에 `_p8x8` / `_p1x48` 이 붙는다
(RGB ablation 에서 조합이 서로 덮어쓴 사고 — 커밋 5eede2f — 의 재발 방지). `hybrid` 는 패치 개념이
없어 접미사가 없다.
