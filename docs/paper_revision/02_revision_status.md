## 3. 데스크톱에서 먼저 확인할 수치 (투고 전 필수)

1. **Table 6 G3-lite S=1.49**: fold 평균 r_N(43.6%)·r_A(15.2%)로 재계산하면 1.35다. 같은 방법으로 B0·G2·G3-full 은 ±0.04 안에서 맞는다. fold 별 S 를 평균했는지, 아니면 오기인지 원 JSON 에서 확인한다.
2. **Table 3 CPU·1024 클래스 가중치 π=3.3%**: 2.056 이라 2.05 와 2.06 의 반올림 경계에 있다. 원 JSON 값으로 맞춘다.
3. **§6 한계의 보조 지연 수치**(0.94 대 1.53ms): 노트북·무작위 초기화 모델 값이다. E1 결과가 나오면 학습된 모델 수치로 교체한다.
